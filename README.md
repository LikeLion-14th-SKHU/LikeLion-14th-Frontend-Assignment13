# Figma → Tailwind 연결

| Figma | Tailwind | 설명 |
| --- | --- | --- |
| Vertical Auto Layout | `flex flex-col` | 카드 내용을 위에서 아래로 배치합니다. |
| Horizontal Auto Layout | `flex items-center` | 프로필 원과 정보를 가로로 배치합니다. |
| Fill Container | `w-full`, `flex-1` | 부모 영역을 채우거나 남은 공간을 사용합니다. |
| Wrap | `flex flex-wrap` | 태그가 공간이 부족하면 다음 줄로 이동합니다. |
| Hug Contents | `w-fit h-auto` | 내용과 패딩에 맞춰 크기를 정합니다. |
| Gap | `gap-[60px]`, `gap-[30px]`, `gap-[20px]`, `gap-[10px]` | 요소 사이의 간격을 설정합니다. |
| Padding | `p-[50px]`, `px-[40px] py-[10px]` | 카드와 태그의 안쪽 여백을 설정합니다. |
| Alignment | `items-center`, `items-end` | 요소를 가운데 또는 오른쪽에 정렬합니다. |
| Radius | `rounded-[30px]`, `rounded-[20px]` | 카드와 태그의 모서리를 둥글게 만듭니다. |
