# LikeLion-14th-Assignment-Template
🦁 SKHU 멋쟁이사자처럼 14기 과제 PR 템플릿 레포지토리입니다.

*조건2

Figma: Vertical Auto Layout
Tailwind: flex flex-col
설명: 카드 안의 프로필·태그·버튼 영역을 세로로 배치

Figma: Horizontal Auto Layout
Tailwind: flex (flex-row)
설명: 프로필 원과 이름을 가로로 배치

Figma: Alignment 세로 중앙
Tailwind: items-center
설명: 가로로 배치된 프로필 원과 이름을 세로 기준 중앙 정렬


Figma: Wrap
Tailwind: flex flex-wrap
설명: 기술 태그가 공간이 부족하면 다음 줄로 이동하도록 구현

Figma: Hug Contents
Tailwind: 너비 지정 없이 padding만 적용 (px-10 py-3.5)
설명: 태그·버튼이 글자 길이만큼 크기가 정해지도록 구현

Figma: Fill Container
Tailwind: w-full, flex-1
설명: 내부 영역이 카드 너비를 채우고, 이름 영역은 남은 공간을 채우도록 구현

Figma: Gap / Padding
Tailwind: gap-[60px], p-[50px] 등
설명: Figma 수치를 그대로 px 값으로 적용

Figma: Alignment 오른쪽
Tailwind: justify-end
설명: GitHub 버튼을 오른쪽 끝에 정렬
